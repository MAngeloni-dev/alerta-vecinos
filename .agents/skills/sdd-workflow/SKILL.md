# Skill: Flujo de Trabajo SDD (Spec-Driven Development)

Esta skill guía la ejecución estructurada de tareas y el control de calidad riguroso en el proyecto.

## Fases del Ciclo SDD
1. **Explore:** Inspeccionar el DOM, componentes existentes y necesidades del usuario final.
2. **Propose:** Explicar el *Why* antes del *How*. Presentar la solución técnica y UX antes de escribir código.
3. **Tasks:** Desglosar en pasos atómicos y manejables.
4. **Apply:** Ejecutar el código garantizando fidelidad visual a Figma y los 5 estados de interacción.
5. **Verify:** Validar con la lista de verificación (DoD):
   - Prueba en resolución móvil.
   - Navegación completa por teclado.
   - Verificación de contraste accesible WCAG AA.
   - Cero logs ni dependencias residuales.
